# ⚡ QUICKSTART - Démarrage Rapide en 5 Minutes

## Pour les FORMATEURS 👨‍🏫

### Voir les Recommandations

1. **Depuis "Mes formations":**
   - Sélectionnez une formation
   - Cliquez le bouton **"Recommandations"** (violet)
   - ✅ Fenêtre avec livres et vidéos s'ouvre

2. **Depuis "Gerer les leçons":**
   - Ouvrez une formation
   - Cliquez le bouton **"Recommandations"** (violet)
   - ✅ Fenêtre avec livres et vidéos s'ouvre

### Publier une Recommandation

1. Sélectionnez un **livre** OU une **vidéo**
2. Cliquez **"✓ Publier comme leçon"** (vert)
3. ✅ Message: "La leçon a été publiée avec succès!"

### Autres Actions

- 🌐 **Ouvrir dans navigateur**: Vérifier avant de publier
- 🔄 **Actualiser**: Recharger les recommandations
- Bascule entre onglets: **"📚 Livres"** et **"🎥 Vidéos"**

---

## Pour les APPRENANTS 👨‍💻

### Voir les Recommandations

1. Ouvrez une **Formation Learning**
2. Cliquez l'onglet **"Livres Recommandés"** ou **"Vidéos Recommandées"**
3. ✅ Liste des ressources s'affiche

### Publier une Recommandation

1. Sélectionnez un **livre** OU une **vidéo**
2. Cliquez **"✓ Publier comme leçon"** (vert)
3. ✅ La leçon est immédiatement ajoutée à votre formation

### Autres Actions

- 🌐 **Ouvrir dans navigateur**: Lire/regarder la ressource
- 🔄 **Actualiser**: Recharger les recommandations

## Troubleshooting Rapide

| Problème | Solution |
|---------|----------|
| Rien ne s'affiche | Cliquez 🔄 "Actualiser" |
| Pas de livres/vidéos | Vérifiez que les APIs répondent (consulter .env) |
| Titre trop long | Sera automatiquement raccourci (normal) |
| Double leçon | Titre déjà existant - choisir une autre ressource |
| Lien ne s'ouvre pas | Utiliser 🌐 "Ouvrir dans navigateur" |
